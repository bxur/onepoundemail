## 功能配置：该有的都有

别看价格低，功能上人家可不含糊。所有套餐都标配了这些：

**基础通讯协议全支持**：SMTP、IMAP、POP3这几种主流邮件协议都能用，意味着你可以在手机邮件app、Outlook、Foxmail这些常用客户端里随便折腾。

**DirectAdmin管理面板**：这个面板在行业里口碑不错，界面简洁，不需要啥技术背景也能轻松上手。添加邮箱账户、设置转发规则、查看使用量，都是几下点击的事儿。

**两种Webmail选择**：提供了CrossBox和Roundcube两种网页版邮箱界面。CrossBox看着比较现代化，Roundcube则是老牌开源方案，稳定性强。反正你喜欢哪个用哪个，甚至可以换着用。

**Catch-All功能**：这个功能挺实用的。简单说就是，任何发到你域名的邮件，即使邮箱地址不存在，也能被一个指定的账户接收。对于临时注册一些网站服务特别方便，用完直接不管就行。

**IMAPSync迁移工具**：如果你之前在别的邮箱服务商那儿，想把旧邮件搬过来，这个工具能帮上忙。虽然我没实际用过，但看官网的描述，应该能省不少手动导出导入的麻烦。

**智能垃圾邮件过滤**：这个年头，没有垃圾邮件过滤的邮箱基本没法用。OnePoundEmail用的是他们自己优化过的过滤系统，根据用户反馈来看，效果还不错，既不会放过太多垃圾邮件，也不会误伤正常邮件。

## 有什么需要注意的？

说了这么多好话，也得提醒几个可能的槽点：

**没有国内支付方式**：人家是英国公司，支持的都是国际信用卡、PayPal这些。如果你没有双币信用卡或PayPal账户，购买起来会有点麻烦。不过现在办张虚拟信用卡也不难，很多银行app里都能申请。

**服务器在美国**：虽然公司在英国，但根据社区讨论的信息，邮件服务器实际部署在美国。这意味着国内访问速度可能没有香港、新加坡节点那么快，不过邮件服务本身对延迟要求不高，影响不算太大。

**发信限制每小时300封**：这个限制对于正常使用来说绰绰有余，但如果你想用它来群发营销邮件，那就别想了。不过说实话，这个限制反而是好事，能保证IP信誉度，你发的正常邮件不容易被当成垃圾邮件拦截。

**不支持向某些特定域名发送**：根据官方说明，他们的服务器无法向QQ邮箱发送邮件。这对国内用户来说确实是个问题，如果你的主要通讯对象都用QQ邮箱，那这个服务可能不太适合你。
